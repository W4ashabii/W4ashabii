## Selected Projects

### Nepali AI & OCR

Research and engineering projects focused on **Nepali and Devanagari language technology**, including OCR datasets, synthetic data generation, model fine-tuning, evaluation pipelines, and document understanding.

### [Agentic NEPSE](https://github.com/W4ashabii/agentic_nepse)

An experimental agentic machine-learning system for **Nepal Stock Exchange analysis and forecasting**, combining machine learning, financial analysis, backtesting, and local LLM-based agents.

### [Nepali Morpheme Segmentation](https://github.com/W4ashabii)

Research on **Nepali morphological segmentation** using byte-level transformer models, with a focus on generalization to previously unseen roots.

### [DeepGyan](https://github.com/W4ashabii/deepgyan)

An AI-powered educational and knowledge system exploring how AI can be used to make learning materials more interactive and accessible.

### Nepali / Devanagari OCR Evaluation

Building tools and benchmarks for evaluating OCR and vision-language models on **Nepali and Devanagari documents**, with an emphasis on reproducible evaluation.
